# Security Policy

RG Studios takes security seriously and appreciates responsible disclosure of
security-related issues.

This document explains how to report security vulnerabilities and what to expect.

---

## Supported Scope

Security reports may include issues related to:

- RG Studios public repositories
- Documentation or resources published under RG Studios
- Public-facing tools or services officially linked by RG Studios

This repository itself mainly contains documentation and public information.

---

## Reporting a Vulnerability

If you discover a potential security issue, please report it **privately**.

### Preferred Contact Method

📧 Email: contact@rixstongamer.xyz  

Please include:
- A clear description of the issue
- Steps to reproduce (if applicable)
- Any relevant logs, screenshots, or references

---

## Disclosure Guidelines

- ❌ Do **not** publicly disclose security issues before they are reviewed
- ❌ Do **not** open public GitHub issues for security vulnerabilities
- ✅ Give reasonable time for investigation and response

Responsible disclosure helps keep users and projects safe.

---

## Response Expectations

RG Studios will:
- Acknowledge valid security reports when possible
- Review the issue in a reasonable timeframe
- Take appropriate action based on severity

Please note that response times may vary, as support is provided on a
**best-effort basis**.

---

## Thank You

We appreciate your efforts to help keep RG Studios projects and resources secure.
